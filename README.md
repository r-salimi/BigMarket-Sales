# Big Mart Sales Prediction

## Project Overview
Predicting item outlet sales using machine learning regression models.

## Dataset
Big Mart Sales dataset.

## Approach
- Exploratory Data Analysis
- Data cleaning
- Missing value imputation
- Feature encoding
- Feature scaling
- Train-test split
- Cross-validation

## Models
- Dummy Regressor
- Linear Regression
- Ridge Regression
- KNN Regression
- Random Forest

## Evaluation
Models were evaluated using:
- MAE
- RMSE
- R²
